> **Это не конец. Репозиторий в работе и будет активно дополняться.**

## О проекте

| | |
|---|---|
| Тестируемое приложение | **WorkDo** — «Автоматизация для охраняемых предприятий» |
| Адрес | https://www.workdo.ru |
| Раздел | Охрана → Сотрудники (`/security/employees`) |
| Стек (по данным HAR) | Next.js (App Router, Server Actions), React 19.3, Auth.js, Vercel + Cloudflare, Яндекс.Метрика / Вебвизор |
| Дата тестирования | 05.10.2026, 15:22–15:23 (UTC+03:00) |
| Браузер | Firefox 157.0, HTTP/3 |
| Тестовая запись сотрудника | `5b6b4e54-e511-42bc-929c-6a367cead77c` |
| Тенант | `tenant-id = 38` |

**Цель репозитория** — зафиксировать найденные дефекты и приложить к ним доказательства
(скриншоты, сетевые дампы), чтобы их можно было воспроизвести и передать в разработку.
